# 🏠 Previsão de Preços de Imóveis
## 🎯 Objetivo

O objetivo do projeto é criar um modelo capaz de estimar o **preço de um imóvel** utilizando informações disponíveis no dataset.

A variável alvo (*target*) do projeto será o **Preço do imóvel**

As demais características serão utilizadas como variáveis (*features*) para ajudar o modelo a realizar suas previsões.


## 🤖 Tecnologias utilizadas

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab
